# Запуск сервиса

Сервис — FastAPI-приложение, точка входа — `main.py`.

## Предусловия

Убедись, что установлены зависимости:

```bash
source .venv/bin/activate   # или python -m venv .venv при первом запуске
pip install -r requirements.txt
```

## Запуск

```bash
uvicorn main:app --reload
```

- По умолчанию слушает `http://127.0.0.1:8000`.
- `--reload` — автоперезапуск при изменении кода (для локальной разработки).
- Порт можно сменить: `uvicorn main:app --reload --port 8080`.

## Проверка работоспособности

```bash
curl http://127.0.0.1:8000/health   # статус сервиса (ожидаем {"status": "ok"})
curl http://127.0.0.1:8000/         # корневой эндпоинт
```

Если оба эндпоинта отвечают — сервис поднят. Иначе смотри логи процесса (ищи трейсбек uvicorn).

## Остановка

- Интерактивно: `Ctrl+C` в терминале uvicorn.
- Фоновый процесс: найди PID (`lsof -i :8000` или `ps aux | grep uvicorn`) и заверши его.

## Примечания

- `main.py` импортирует и регистрирует роутеры при старте — при добавлении нового роутера убедись, что он подключён в `main.py`, иначе эндпоинты не появятся.
- Билд/миграции/внешние зависимости в текущей версии не требуются — проект standalone.
