# Проектные ER-диаграммы

Четыре проекции схемы из [DATABASE_SCHEMA.md](../DATABASE_SCHEMA.md#schema-diagrams):

- [Пользователи и доступ](access.mmd)
- [Репозиторий и ревью](review.mmd)
- [Исполнение, контекст и публикация](execution.mmd)
- [Биллинг и квота](billing.mmd)

Это исходники Mermaid, соответствующие встроенным диаграммам документа.
Они показывают ключевые поля и связи. Полный словарь всех 34 сущностей,
nullable, состояний и ограничений находится в DATABASE_SCHEMA.md.
Диаграммы описывают проект; реализованных ORM-моделей и миграций этот PR не содержит.
