# Физическая ERD

Диаграммы создаются из **всех колонок и FK SQLAlchemy metadata**, а не вручную
из сокращённых проектных схем. `NULL`/`NOT NULL`, PK, составные FK и их поля
показаны явно. Таблица без списка колонок — внешний родитель из другой проекции.
`o|` указывает необязательный родитель; `||` — обязательный.

Mermaid показывает связи с возможностью множества детей. UNIQUE, частичные
индексы, CHECK и циклические ограничения описаны в
[словаре](../DATABASE_SCHEMA.md) и полностью реализованы в миграции `0001`;
кратность на картинке не заменяет эти ограничения.

Перегенерация: `uv run python scripts/export_erd.py`.
Тест `test_erd_matches_metadata` проверяет, что сохранённые диаграммы актуальны.
