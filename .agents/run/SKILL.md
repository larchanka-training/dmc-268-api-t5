# Запуск сервиса: workflow

Сервис — FastAPI-приложение, точка входа `main.py`.

## Workflow: запустить и проверить

1. **Предусловия** — зависимости:
   ```bash
   source .venv/bin/activate      # при первом запуске: python -m venv .venv
   pip install -r requirements.txt
   ```
2. **Запуск** (в фоне или отдельном терминале):
   ```bash
   uvicorn main:app --reload      # http://127.0.0.1:8000; порт: --port 8080
   ```
3. **Проверка работоспособности** — последовательно:
   ```bash
   curl http://127.0.0.1:8000/health   # ожидаем {"status":"ok"}
   curl http://127.0.0.1:8000/         # ожидаем {"message":"Welcome to DMC-268 Team 5 API"}
   ```
   Считай шаг успешным, только если оба ответа совпали с ожидаемыми телами.
4. **При падении** — прочитай трейсбек uvicorn из логов процесса; типовые причины: незакрытый порт (`lsof -i :8000`), необъявленный роутер в `main.py`, неустановленная зависимость.

## Workflow: остановить

- Интерактивный процесс: `Ctrl+C`.
- Фоновый: `lsof -i :8000` → PID → `kill <PID>`; подтверди остановку повторным `curl /health` (ожидаем connection refused).

## Критерий успеха

- Процесс uvicorn запущен без трейсбеков в логах.
- `/health` и `/` отвечают 200 с телами, совпадающими с ожидаемыми выше.

Если критерий не достигнут — workflow не завершён: диагностируй по шагу 4 и повтори.
